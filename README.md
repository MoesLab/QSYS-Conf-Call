# Q-SYS Conference Room — live demo

**[Open the demo](https://moeslab.github.io/QSYS-Conf-Call/)**

A teleconference room designed in Q-SYS Designer, running in the browser with no Core needed:

- **Conference Control UCI** on a TSC-80-G2: POTS dialer with contacts and call progress, incoming volume, room speaker and mic mute, camera selection.
- **13 microphones** through a 200 ms AEC into a gating automixer: at most 2 open mics, Mic 4 as the default open mic, plus a Moderator snapshot bank.
- **Mixer 6×15** with every crosspoint at 0 dB; far-end feeds are mix-minus.
- **Cameras** NC-12x80, NC-20x60 and NC-110 through a Mediacast router to the USB video bridge.
- **Command Scheduler** plays the Audio Player weekdays 12:00–13:00.
- **Monitoring**: Ping to a Monitoring Proxy for Reflect.

Use the test tools to ring the room, start a PC call or presentation, jump the clock, or unplug a monitored device.
